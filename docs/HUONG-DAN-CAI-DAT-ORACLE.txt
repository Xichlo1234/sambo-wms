    - Vẫn 0 đồng nếu chỉ dùng tài nguyên có nhãn "Always Free".
1.6 Đặt cảnh báo chi phí để chắc chắn không bị tính tiền:

    -> Amount: 1 (USD) -> Alert: 1% actual spend -> email của bạn

PHẦN 2 - TẠO KHÓA SSH TRÊN MÁY WINDOWS (lưu ổ D)
=====================================================================
2.1 [PowerShell]:
    ssh-keygen -t ed25519 -f D:\sambo-oracle -C sambo-oracle
    -> passphrase: đặt mật khẩu cho khóa hoặc Enter để bỏ qua.
2.2 Đặt quyền riêng tư cho khóa:
    icacls D:\sambo-oracle /inheritance:r /grant:r "$($env:USERNAME):R"
2.3 Hiện khóa công khai:
    Get-Content D:\sambo-oracle.pub
    -> sao chép NGUYÊN dòng bắt đầu bằng ssh-ed25519 ...
2.4 Chép 2 file D:\sambo-oracle và D:\sambo-oracle.pub vào USB.

PHẦN 3 - TẠO MÁY CHỦ (INSTANCE)
=====================================================================
3.1 Menu -> Compute -> Instances -> Create instance.
3.2 Name: sambo-wms
3.3 Image and shape -> Edit:
    - Change image -> Ubuntu -> Canonical Ubuntu 24.04 (KHÔNG chọn
      bản "Minimal") -> Select image.
    - Change shape -> Ampere -> VM.Standard.A1.Flex
      -> Number of OCPUs: 2 ; Amount of memory (GB): 12 -> Select shape.
    - Phải thấy nhãn "Always Free-eligible".
3.4 Networking: giữ mặc định (Create new virtual cloud network, Assign
    a public IPv4 address = Yes).
3.5 Add SSH keys -> Paste public keys -> dán dòng ssh-ed25519 ... (2.3)
3.6 Boot volume -> tích "Specify a custom boot volume size" -> 100 GB
    (Always Free cho tổng 200 GB).
3.7 Create. Chờ trạng thái RUNNING (1-3 phút) -> ghi lại Public IP
    address.

>>> Báo "Out of capacity for shape VM.Standard.A1.Flex":
    - Đổi Placement -> Availability domain khác (AD-1/2/3) rồi thử lại.
    - Thử lại vào sáng sớm/đêm khuya, hoặc vài giờ sau.
    - Làm bước 1.5 (Pay As You Go) - thường hết lỗi này.

PHẦN 6 - TÊN MIỀN & CLOUDFLARE TUNNEL
=====================================================================
6.1 Chưa có tên miền trên Cloudflare:
    dash.cloudflare.com -> đăng ký -> Add a site -> nhập tên miền
    -> gói Free -> đổi nameserver tại nơi mua tên miền theo 2 địa chỉ
    Cloudflare đưa -> chờ báo Active.
    (Hoặc mua .com ngay tại Cloudflare: Domain Registration ->
     Register Domains - khoảng 10-11 USD/năm.)

6.2 Zero Trust -> Networks -> Tunnels -> Create a tunnel -> Cloudflared
    -> tên: sambo-wms -> Save tunnel.
6.3 Chọn hệ điều hành Debian, kiến trúc arm64-bit (máy chủ Oracle
    là ARM - KHÔNG chọn 64-bit/amd64) -> chép và chạy TỪNG lệnh
    Cloudflare hiện ra trong cửa sổ [Máy chủ]. Lệnh cuối dạng:
    sudo cloudflared service install eyJhIjoi.....
    -> Connector chuyển "Connected".
6.4 Next -> Public Hostname:
    Subdomain: wms ; Domain: <ten-mien> ; Type: HTTP ; URL: localhost:4000
    -> Save tunnel.
6.5 [Máy chủ] - bật cookie bảo mật HTTPS:
    sudo sed -i 's/^COOKIE_SECURE=.*/COOKIE_SECURE=true/' /opt/sambo-wms/shared/.env && sudo systemctl restart sambo-wms
6.6 Mở https://wms.<ten-mien> trên máy tính và điện thoại (4G).

6.7 Chỉ cho nhân viên vào (BẮT BUỘC khi vận hành thật):
    Zero Trust -> Access -> Applications -> Add an application
    -> Self-hosted -> Application domain: wms.<ten-mien>
    -> Policy: Allow ; Include: Emails ending in @<email-cong-ty>
       (hoặc "Emails" và nhập từng email) -> Save.

PHẦN 8 - SAO LƯU
=====================================================================
A. Sao lưu ra ngoài lên Cloudflare R2 (10 GB miễn phí)
8.1 Cloudflare -> R2 Object Storage -> Create bucket: sambo-wms-backup
8.2 R2 -> Manage API tokens -> Create API token -> Object Read & Write
    -> chỉ bucket sambo-wms-backup -> ghi lại Access Key ID, Secret
    Access Key, Endpoint.
8.3 [Máy chủ]:
    sudo apt install -y rclone
    sudo rclone config
      n -> name: r2 -> Storage: s3 -> provider: Cloudflare
      -> env_auth: Enter -> access_key_id / secret_access_key: dán
      -> region: Enter -> endpoint: dán -> còn lại Enter -> y -> q
8.4 Thử ngay:
    sudo R2_REMOTE=r2:sambo-wms-backup bash /opt/sambo-wms/current/deploy/backup.sh
    -> "Kiểm tra toàn vẹn: OK" và "Đã đồng bộ lên r2:sambo-wms-backup"
8.5 Lịch tự động 02:00 hằng đêm:
    echo '0 2 * * * root R2_REMOTE=r2:sambo-wms-backup bash /opt/sambo-wms/current/deploy/backup.sh' | sudo tee /etc/cron.d/sambo-wms-r2
8.6 R2 bucket -> Settings -> Object lifecycle rules -> xóa file > 90 ngày.

B. Sao lưu toàn bộ máy chủ trên Oracle (miễn phí tối đa 5 bản)
8.7 Oracle: Compute -> Instances -> sambo-wms -> Boot volume -> bấm
    tên boot volume -> Boot volume backups -> Create boot volume backup
    -> tên: truoc-van-hanh -> Full -> Create.
    Làm lại trước mỗi lần cập nhật lớn; xóa bản cũ để giữ <= 5 bản.

PHẦN 13 - XỬ LÝ SỰ CỐ
=====================================================================
* "Out of capacity" khi tạo máy chủ -> xem cuối Phần 3.
* SSH báo "Permission denied (publickey)"
  -> đúng người dùng ubuntu@ và đúng file -i D:\sambo-oracle ?
  -> báo "UNPROTECTED PRIVATE KEY FILE": chạy lại lệnh 2.2.
  -> vẫn không vào được: Oracle -> Instance -> Console connection
     (Launch Cloud Shell connection).
* SSH báo "Connection timed out"
  -> máy chủ đang Stopped? Oracle -> Instance -> Start.
* Cloudflare báo lỗi 502 / 1033
  -> sudo systemctl status sambo-wms cloudflared ; khởi động lại cái
     không "active (running)".
  -> cloudflared không chạy được: có thể đã cài nhầm bản amd64 - làm
     lại 6.3 chọn arm64.
* Đăng nhập xong bị đẩy ra -> phải vào bằng https://wms.<ten-mien>.
* Máy chủ bị Oracle dừng/thu hồi do "idle" -> Start lại; làm bước 1.5
  (Pay As You Go) để tránh lặp lại.
* Ổ đĩa đầy -> xóa bản sao lưu cũ trong /var/lib/sambo-wms/backups (đã
  có trên R2) hoặc tăng boot volume (tổng miễn phí 200 GB).
* Mất máy chủ hoàn toàn -> tạo máy chủ mới (Phần 3-6), tải bản .dump và
  .uploads.tar.gz mới nhất từ R2 về /var/lib/sambo-wms/backups, chạy
  restore.sh với file .dump, giải nén .uploads.tar.gz vào
  /var/lib/sambo-wms/uploads (hoặc tạo lại máy từ boot volume backup).

Tài liệu chi tiết: https://github.com/Xichlo1234/sambo-wms (thư mục docs)
