PHẦN 1 - TẠO KHÓA SSH TRÊN MÁY WINDOWS (lưu vào ổ D)
=====================================================================
1.1 [PowerShell]:
    ssh-keygen -t ed25519 -f D:\sambo-vps -C sambo-vps
    -> hỏi passphrase: đặt 1 mật khẩu cho khóa (hoặc Enter để bỏ qua)
    -> tạo 2 file: D:\sambo-vps (khóa BÍ MẬT) và D:\sambo-vps.pub
       (khóa công khai).
1.2 Đặt quyền riêng tư cho khóa bí mật (Windows bắt buộc):
    icacls D:\sambo-vps /inheritance:r /grant:r "$($env:USERNAME):R"
1.3 Xem khóa công khai để dán vào trang tạo VPS:
    Get-Content D:\sambo-vps.pub
    -> sao chép NGUYÊN dòng bắt đầu bằng ssh-ed25519 ...
1.4 Sao chép 2 file D:\sambo-vps* vào USB cất giữ. Mất khóa = không
    vào được VPS (khi đó phải dùng console web của nhà cung cấp).

PHẦN 3 - KẾT NỐI VÀ BẢO MẬT VPS
=====================================================================
3.1 [PowerShell] - kết nối (lần đầu hỏi yes/no -> gõ yes):
    ssh -i D:\sambo-vps root@<IP>
    (VPS dùng mật khẩu: ssh root@<IP> rồi nhập mật khẩu root)

3.2 [VPS] - cập nhật hệ thống (vài phút; có màn hình hỏi thì Enter):
    apt update && apt upgrade -y

3.3 Đặt múi giờ Việt Nam:
    timedatectl set-timezone Asia/Ho_Chi_Minh

3.4 Tạo người quản trị riêng "sambo" (không làm việc bằng root):
    adduser sambo
    -> đặt mật khẩu (ghi lại), các câu hỏi khác Enter.
    usermod -aG sudo sambo
    mkdir -p /home/sambo/.ssh && cp /root/.ssh/authorized_keys /home/sambo/.ssh/ && chown -R sambo:sambo /home/sambo/.ssh && chmod 700 /home/sambo/.ssh

3.5 Bật tường lửa - CHỈ mở cổng SSH (web đi qua Cloudflare Tunnel):
    ufw allow OpenSSH && ufw --force enable && ufw status

3.6 Tự cài bản vá bảo mật & chặn dò mật khẩu:
    apt install -y unattended-upgrades fail2ban git curl
    dpkg-reconfigure -plow unattended-upgrades
    -> chọn Yes.

3.7 Thêm bộ nhớ đệm swap 2 GB (giúp build ổn định):
    fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab

3.8 Thoát và đăng nhập lại bằng người dùng sambo:
    exit
    [PowerShell]  ssh -i D:\sambo-vps sambo@<IP>
    -> Từ nay luôn đăng nhập bằng sambo. Lệnh quản trị dùng sudo.

3.9 (Khuyến nghị, chỉ làm khi 3.8 ĐĂNG NHẬP ĐƯỢC bằng khóa) - tắt
    đăng nhập bằng mật khẩu và đăng nhập root:
    sudo sed -i -e 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' -e 's/^#\?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config && sudo systemctl restart ssh
    Mở THÊM một cửa sổ PowerShell, thử ssh -i D:\sambo-vps sambo@<IP>
    -> vào được mới đóng cửa sổ cũ.

PHẦN 6 - TÊN MIỀN & CLOUDFLARE TUNNEL (truy cập HTTPS)
=====================================================================
6.1 Chưa có tên miền trên Cloudflare:
    dash.cloudflare.com -> đăng ký tài khoản -> Add a site -> nhập tên
    miền -> chọn gói Free -> Cloudflare cho 2 nameserver -> vào trang
    nơi mua tên miền đổi nameserver sang 2 địa chỉ đó -> chờ Cloudflare
    báo Active (vài phút đến vài giờ).
    (Có thể mua tên miền .com ngay trong Cloudflare: Domain
     Registration -> Register Domains.)

6.2 Zero Trust -> Networks -> Tunnels -> Create a tunnel -> Cloudflared
    -> tên: sambo-wms -> Save tunnel.
6.3 Chọn Debian, 64-bit -> chép và chạy TỪNG lệnh Cloudflare hiện ra
    trong cửa sổ [VPS]. Lệnh cuối có dạng:
    sudo cloudflared service install eyJhIjoi.....
    -> Connector chuyển "Connected".
6.4 Next -> Public Hostname:
    Subdomain: wms ; Domain: <ten-mien> ; Type: HTTP ; URL: localhost:4000
    -> Save tunnel.
6.5 [VPS] - bật cookie bảo mật HTTPS:
    sudo sed -i 's/^COOKIE_SECURE=.*/COOKIE_SECURE=true/' /opt/sambo-wms/shared/.env && sudo systemctl restart sambo-wms
6.6 Mở https://wms.<ten-mien> trên máy tính và điện thoại.

6.7 Chỉ cho nhân viên vào (BẮT BUỘC khi vận hành thật):
    Zero Trust -> Access -> Applications -> Add an application
    -> Self-hosted -> Application domain: wms.<ten-mien>
    -> Policy: Action Allow ; Include: Emails ending in @<email-cong-ty>
       (không có email tên miền công ty: chọn "Emails", nhập từng email)
    -> Save. Người dùng nhận mã qua email -> vào trang đăng nhập WMS.

PHẦN 8 - SAO LƯU NGOÀI SITE LÊN CLOUDFLARE R2
=====================================================================
8.1 Cloudflare -> R2 Object Storage -> Create bucket: sambo-wms-backup
8.2 R2 -> Manage API tokens -> Create API token -> Object Read & Write
    -> chỉ bucket sambo-wms-backup -> Create -> ghi lại Access Key ID,
    Secret Access Key, Endpoint (https://<id>.r2.cloudflarestorage.com)
8.3 [VPS]:
    sudo apt install -y rclone
    sudo rclone config
      n -> name: r2 -> Storage: s3 -> provider: Cloudflare
      -> env_auth: Enter -> access_key_id / secret_access_key: dán
      -> region: Enter -> endpoint: dán -> còn lại Enter -> y -> q
8.4 Thử ngay:
    sudo R2_REMOTE=r2:sambo-wms-backup bash /opt/sambo-wms/current/deploy/backup.sh
    -> "Kiểm tra toàn vẹn: OK" và "Đã đồng bộ lên r2:sambo-wms-backup"
8.5 Lịch tự động 02:00 hằng đêm:
    echo '0 2 * * * root R2_REMOTE=r2:sambo-wms-backup bash /opt/sambo-wms/current/deploy/backup.sh' | sudo tee /etc/cron.d/sambo-wms-r2
8.6 Cloudflare: bucket -> Settings -> Object lifecycle rules -> xóa
    file cũ hơn 90 ngày.
8.7 Trang nhà cung cấp VPS: bật Backup/Snapshot tự động hằng tuần.

PHẦN 13 - XỬ LÝ SỰ CỐ
=====================================================================
* Không SSH được ("Permission denied")
  -> đúng người dùng (sambo@) và đúng file khóa (-i D:\sambo-vps)?
  -> vẫn không được: dùng Console/VNC trên trang nhà cung cấp VPS.
* Trang báo Cloudflare 502 / 1033
  -> sudo systemctl status sambo-wms cloudflared ; khởi động lại cái
     nào không "active (running)".
* Đăng nhập xong bị đẩy ra
  -> phải vào bằng https://wms.<ten-mien>, không vào bằng http://IP.
* Báo lỗi cơ sở dữ liệu
  -> sudo systemctl status postgresql ; sudo journalctl -u sambo-wms -n 50
* Ổ đĩa đầy
  -> xóa bản sao lưu cũ trong /var/lib/sambo-wms/backups (đã có trên
     R2) hoặc nâng gói ổ đĩa VPS.
* Cập nhật lỗi
  -> update.sh đã tự quay về bản cũ; chụp màn hình lỗi gửi kỹ thuật.
* Mất VPS hoàn toàn
  -> tạo VPS mới, làm lại Phần 3-6, rồi khôi phục bản .dump mới nhất
     tải từ R2 bằng restore.sh; file đính kèm: giải nén file
     .uploads.tar.gz cùng thời điểm vào /var/lib/sambo-wms/uploads.

Tài liệu chi tiết: https://github.com/Xichlo1234/sambo-wms (thư mục docs)
